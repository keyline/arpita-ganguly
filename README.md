# Arpitaz website

A responsive, static HTML/CSS/JavaScript website for Arpitaz Hair & Beauty Family Salon. Open `index.html` locally or upload this folder to any static web host. No build step is required.

The site uses the supplied Arpitaz logo and a restrained orange-led palette derived from it, with DM Sans from Google Fonts. The editorial hero includes three slide-specific banners, automatic fading, manual controls and reduced-motion support. Scroll animations use WOW.js and Animate.css from cdnjs. The Our Work section uses images supplied in `assets/`. The bridal video preview plays the supplied YouTube video inline when the site is hosted over HTTP(S); from a local file it opens YouTube, since YouTube rejects local-file embeds. Update the phone number, email, address and customer quotes in `index.html` whenever the business details change.

Business copy is consolidated from the live Arpitaz homepage and About page. Obvious third-party theme filler, demo spa plans, placeholder staff, placeholder contact details and unrelated blog copy were intentionally excluded.
